# Security policy / 安全政策

## Reporting a vulnerability

Please report security-sensitive issues through GitHub's private vulnerability
reporting feature for this repository when available. If private reporting is
not available, open a minimal issue without secrets or profile data and ask the
maintainer for a private contact channel.

Do not upload Chrome `Local State`, browser profiles, cookies, tokens, backup
files, home-directory paths, or other personal data. Include only the plugin
version, operating system, Chrome channel/version, command used, and a redacted
error message or minimal reproduction.

## 报告安全问题

如 GitHub 提供该功能，请通过本仓库的私密漏洞报告渠道提交安全问题。如果无法私密报告，请只创建不含秘密信息和配置数据的最小化 Issue，并向维护者询问私密联系方式。

请勿上传 Chrome `Local State`、浏览器配置文件、Cookie、令牌、备份文件、用户目录路径或其他个人数据。只需提供插件版本、操作系统、Chrome 通道和版本、执行的命令，以及经过脱敏的错误信息或最小复现步骤。
